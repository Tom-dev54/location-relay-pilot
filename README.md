# 定位接力 · 同事模拟测试

一个无需高德 Key、无需位置后台的静态网页：手机定位 → 复制短信回传 → 接收者查看并保存 → 跳转高德路线。

测试网址：[打开定位接力](https://tom-dev54.github.io/location-relay-pilot/)。请先用手机 Safari 或安卓系统浏览器打开。

只需发布根目录的 `index.html`，所有样式和逻辑已包含其中。高德App负责路线与导航，网页不内嵌地图，不记录行驶轨迹。

## 开发

项目无运行依赖。源码位于 `src/`，生成文件为 `index.html`。

先检查核心逻辑，再将源码合成可直接发布的单文件网页：

```sh
npm test
npm run build
```

成功标志：核心测试全部通过，命令输出 `Built index.html`。修改源码后必须重新构建。

浏览器流程检查使用 Playwright CLI，脚本为 `tests/browser-check.js`；它只对本机 `http://127.0.0.1:8765/` 注入模拟位置，不会进行真机定位或发送短信。

## 数据与边界

- 记录保存在当前浏览器，可导出和导入JSON；它们不会自动同步到其他手机。
- 分享链接的片段包含坐标，不是加密或身份认证。得到链接的人能读取位置，接收者应核对编号和时间。
- 点击高德链接会把目的地坐标提供给高德。拒绝定位、数据无效或无有效位置的记录不会借用旧位置。
- 不要向仓库提交导出的定位记录、真实警情或个人资料。这里只用于自愿参加同事的模拟试点。
- 自动检查验证软件逻辑，不能证明定位精度、短信送达或高德App实际唤起成功；这些需要真机完成。

默认驾车起点由高德取“我的位置”；WGS84坐标用 `dev=1`，GCJ02坐标用 `dev=0`，不进行重复转换。

官方依据：[Android路线](https://lbs.amap.com/api/amap-mobile/guide/android/route)、[iOS路线](https://lbs.amap.com/api/amap-mobile/guide/ios/route)、[网页版标点](https://lbs.amap.com/api/uri-api/guide/mobile-web/point)。

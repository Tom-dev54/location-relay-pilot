# 定位接力：公开测试地图版

## 当前流程

- `/` 是公开测试看板，任何浏览器打开相同裸网址都会读取 `public_positions` 中相同的新测试记录。
- `/send` 是公开测试发送页，没有接收看板入口。3秒公开用途告知后请求定位权限；首次有效新位置立即回传，不设精度门槛。保持前台最多再观察20秒，若报告精度同时改善20%及至少10米，只更新同一条记录一次。整次采集最多60秒。
- 网络暂时故障自动重试最多3次，依次等2、5、10秒；单次请求最多15秒，总自动交付窗口120秒。遵守服务器 Retry-After，超出窗口后转手动重试。重试固定同一编号与内容；已送达精度更新失败仍保留首次位置。后台、关闭或主动停止会取消后续采集和重试，已经发出的请求可能已经送达。
- `/#receive=原密钥` 仍可查看旧私人记录；`/send#t=原令牌` 仍使用旧版主动确认回传。旧私人记录不会迁入公开表。
- 公共接口不需要接收密钥，不返回旧邀请的任何信息。首次公开回传采用随机编号，重复请求按编号及完整内容去重。位置保留7天，最多保存5000条、页面展示最近100条。精度更新令牌只保存在本次发送内存中，服务端仅保存哈希；公开列表不返回该令牌、哈希或首次快照。

## 国内与海外地图

新增大陆/海外自动选择、海外底图/地点/路线、Google与苹果地图入口和分阶段错误提示。`GEOAPIFY_API_KEY` 已配置为服务端secret，真实海外服务与国内高德回归已通过。配置步骤、接口、限制及验证范围见《海外地图接入与验证.md》。以下“五项优化”记录为此前版本的验证结果。

## 高德地图

需要一个 **Web端（JS API）** Key，以及与它配套的 `securityJsCode`。Sites 运行环境配置：

- `AMAP_JS_KEY`：JS API Key。
- `AMAP_SECURITY_CODE`：安全密钥，必须标为 secret。

`/api/map-config` 只向浏览器返回是否配置及公开 JS Key，不返回安全密钥。`/_AMapService/*` 按高德官方服务器代理方式添加安全密钥，目的主机固定，路径只允许坐标转换、逆地理编码、驾车规划、地图样式和 SDK 初始化日志。

地图用官方 `AMap.convertFrom` 把原始 WGS84 转成高德坐标；已为 GCJ02 的记录不再转换。转换失败不把原始 WGS84 直接画到高德底图上。原始坐标仍完整保存。

地点描述采用 `AMap.Geocoder`。附近地点不直接认定为所在建筑；方位为“建筑地图标注点指向采集点”，距离为直线估算。查询失败显示可重试入口，不生成虚构名称。报告精度大于200米时只说明街道片区，不推断具体建筑方位。地图随选中点的报告精度范围缩放，最多放大至17级。

接收者点击“在本页看我到这里的路线”，才请求接收者当前位置。此位置只用于高德驾车路线，不上传到公开回传表。调用 `AMap.Driving` 在网页显示路线；“高德导航”另行唤起 App。

## 控制地图调用次数

手机浏览器定位及位置回传不调用高德。五秒轮询只读取本站记录，不主动重查地图。页面优先查询选中点、最新10条和当前可见历史记录，同时最多处理2条。新修订的坐标独立查询。首次列表不提醒，后续新位置高亮30秒、提供未读数和查看最新按钮，不抢走正在查看的位置与路线；同编号更新只显示位置已更新，并使旧路线失效。坐标转换与地点查询结果在服务器共享缓存24小时，不同浏览器可以复用；驾车路线只在点击按钮时查询，不保存路线结果。

本站代理最多每天300次、每月5000次上游请求。公开 SDK 配置不再按访问次数拦截，也不占用上游请求预算；同一页面复用已加载的 SDK。日期按北京时间计算，缓存命中不扣代理计数；并发申请由数据库原子计数保护。超限或计数服务故障时停止新请求，不影响位置回传和坐标列表。错误结果不缓存。

这些是本站请求上限，不是高德账单或账户配额；SDK 的直接请求、同 Key 的其他使用不受本站代理控制。没有购买套餐或开启付费服务。实际免费资格、有效期及扣费规则需在高德控制台核对，不能承诺永久免费。

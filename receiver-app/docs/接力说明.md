# 换电脑继续开发

完整项目在 GitHub 仓库 `Tom-dev54/location-relay-pilot` 的 `receiver-app/` 目录。仓库根目录仍保留最早的静态定位测试页。

1. 在新电脑克隆仓库，进入 `receiver-app`，安装 Node.js 24 后执行 `npm ci`。
   成功标志：依赖安装完成，没有 npm 错误。
2. 查看 `.env.example`，通过私密方式取得三个地图配置值。不要把实际密钥提交到 GitHub。
   成功标志：配置名称齐全；源码、聊天交接文档里没有密钥值。
3. 执行 `node --import ./tests/register-ts.mjs --test tests/*.test.mjs`，再执行 `npm run build`。
   成功标志：测试全部通过，生成 `dist/server` 与 `dist/client`。
4. 继续维护现有网站时，需要有现有 Sites 项目的编辑和发布权限。`.openai/hosting.json` 指向原项目。不要重新创建项目或改写已发布的数据库迁移。
   成功标志：确认正在维护原网址、原项目和原数据库。
5. 如果迁移到其他服务器，另外迁移数据库及运行配置。数据库保存在云端，不在 GitHub 或 env 文件里。
   成功标志：在新部署读取到应保留的数据，旧私人入口仍与公开测试隔离。

只有 env 文件不够；换电脑至少需要本仓库、私密配置、现有服务访问权限。本仓库不含真实位置数据、浏览器缓存、手机截图和部署凭证。针对具体用户记录的临时线上排障脚本不作为公开交接材料；自动化单元测试使用虚构坐标。

## 地图加载修复

- `/api/map-config` 只读取公开 SDK 配置，不再计每日 100 次／每月 1,000 次的访问预算。
- 已经加载的高德 SDK 在当前页面复用。实际地图服务的缓存与请求预算仍独立存在，见 `lib/map-budget.ts`，这些数值不是服务商账户额度。
- 海外地图默认用约 1 秒完成国家视图到定位点的动画，动画期间暂时禁用拖动、缩放，完成后恢复。系统开启“减少动态效果”时直接显示定位点。
- 页面不展示动画实现说明或翻译规则说明。

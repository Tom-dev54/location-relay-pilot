# 海外建筑与地点补充

使用 Overture 开放建筑与地点瓦片（本次验证版本 2026-09-23.1），保留现有 Geoapify 道路底图和 MapLibre 绘图。国内默认高德不变。无新增 Key、账号或地图商付费调用；服务端仍消耗计算、缓存和网络资源。

## 运行方式

- 街区级别（zoom 14 及以上）按视野加载 Overture 数据，每次请求固定一个发布版本；低倍全国图不加载建筑明细。
- `/api/world-map/overture/buildings/14/{x}/{y}` 与 `places` 是同源只读端点。服务器读取固定 PMTiles 档案的 HTTP Range，不接收任意上游地址。
- 范围校验、12 秒上游超时、8 MiB 资源上限、最多 16 个不同瓦片同时处理；相同请求合并，成功瓦片缓存一天，失败不进入持久缓存并短暂退避 10 秒。
- 建筑保留原始多边形，剥离不用于显示的元数据；不画地下建筑。该图层不表示入口或楼层。
- 地点只保留名字、分类、可信度等显示字段，过滤可信度低于 0.8 及标记为已关闭的地点。电话、社交链接等不传入浏览器。名称优先已有中文，其次现有词典，未知名称显示中文类别及原名，不生成虚构楼名。
- 公共设施优先在 zoom 14 显示，其他高可信度地点 zoom 15、其余 zoom 16；保持文字避让，不把所有地点挤在同一屏。
- 建筑在道路下方，精度圆圈、定位标记、路线仍在上方。补充图层失败不阻断底图和导航；重载页面可重试。
- 进入地图时最多同时预热目标建筑、地点两张瓦片，不让补充图层阻挡原有一秒定位动画。
- 无 WebGL 的旧浏览器继续使用原有栅格兼容底图，本次新增矢量图层需支持 WebGL 的浏览器。

## 验证与更新

以廊曼机场西侧公共城区作为地图显示样本，不提交任何定位记录。验证实际瓦片、手机视口、标记和导航、补充失败降级、发送端无看板入口。单元测试覆盖名称/可信度/停业过滤、几何保持、缓存与并发、无效请求和错误重试。

服务端每小时读取官方目录的最新发布版本，缓存键包含版本号；目录不可用时沿用已知版本。这样不依赖会被上游清理的历史档案。更新仍需保留名称、可信度和几何校验；字段不完整的地点不显示，避免把错误内容画到地图。

## 来源与许可

- Overture 建筑（ODbL），包含 OpenStreetMap、Microsoft ML Buildings、Google Open Buildings 等。图面保留 OSM 与 Overture 署名；完整源数据及许可见下列链接。
- Overture Places 由多个来源组成，许可及来源见官方说明。本程序对公开数据作显示字段精简、可信度筛选及分类映射，不宣称为现场核验结果。
- Geoapify、OpenMapTiles、OpenStreetMap 的现有署名保留。

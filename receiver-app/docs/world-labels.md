# 海外地图中文显示与进场动画

2026-09-27：用户同意在原名旁补充参考译名。本次不增加翻译服务账号或接口费用。

## 名称处理

1. 优先使用地图数据的 `name:zh-Hans`、`name:zh`、`name:zh-Hant` 等中文字段，同时保留原名。地图已有名称也属于参考数据，不证明用户所在建筑。
2. 精确匹配少量品牌中文名：Adidas → 阿迪达斯（[品牌官方资料](https://static1.adidas.com.cn/ecp-cms/cdn-file/tac/content/WMS/0/TAC_PRIVACY.html)）；Subway → 赛百味（[中国官网](https://subway.com.cn/)）。赛百味必须同时匹配餐饮类别，避免把地铁站误译成商铺。
3. `lib/world-labels.ts` 的 `referenceNames` 是人工编写的辅助译名/音译，对照本次 Geoapify 矢量数据中实际的英语字段。主要补充廊曼机场周边道路、片区、到达/出发区及部分店铺。全部加 `†`，表示参考译名，不冒充官方地名。v24 增加廊曼西侧城区抽样中实际出现的店铺与设施英文名对照；未匹配的泰文名称保留原名。
4. 没有中文名或匹配译名时，显示数据里的场所类别（例如“珠宝店 / BNE”“咖啡店 / Camden”）。这只是类型说明，不是把店名翻译完毕。
5. 词典只影响显示，不用于地址搜索、坐标计算、精度判断或导航目的地。大小写忽略，采用完整字符串匹配；不对任意名称做子串替换。不存在地点自动翻译或全球中文名称全覆盖的承诺。以后可从更完整、有授权的译名数据源补充。
6. 兼容图片底图无法改写图内文字，界面明确提示保留原文，可切回高清矢量图。原始地图版权归属保留。

## 动画

首次加载时显示明确的地图准备状态，等待真实国家尺度的区域底图准备好后淡出遮罩，预加载有限的目的地瓦片，再用约 1 秒平滑放大到目标位置。区域尺度根据窗口大小适配，不承诺按各国边界精确框选。预加载复用已有缓存，最多 7 块瓦片、并发 3 个、最长 6 秒，不下载整个国家；首次进场完成前锁定缩放操作，确保默认动画完成。没有人为延长网络等待。刷新位置列表不重新创建地图；切换位置中断上一段动画，后续聚焦约 0.5 秒。系统偏好减少动态效果时不播放缩放动画。现有底图在补充细节时继续显示。

## 验证

自动测试验证中文字段优先级、参考译名标记、类型回退、地铁/餐饮同名区分，以及位置描述距离不变。真实浏览器验证首次加载、参考点移动的多个中间帧、快速切换、刷新不重播和减少动态效果。实机微信和国内无代理网络速度仍需现场核对，不能由本地浏览器模拟替代。

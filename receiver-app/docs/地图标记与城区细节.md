# 地图标记与城区细节

## 修改

- 国内高德、海外矢量及兼容地图共用同一个 SVG 图钉。当前选中记录显示蓝色和“当前查看”，其他记录用浅色。图钉尖端对应坐标，文字不改变坐标锚点。点击或键盘操作可选择对应记录。
- 小街道名称从 13.5 级开始显示；第二、三级地点分别从 14、15 级开始显示。保留文字碰撞避让，不强制叠字。
- 已有建筑轮廓提高对比度，去掉重复浅色屋顶遮盖；17 级以后显示数据中已有的门牌。
- 有中文名或参考译名的道路继续双语显示；没有中文名的道路用原有可读名称，减少重复“道路”字样挤占空间。

## 数据边界

检查了用户截图中廊曼机场西侧区域的 Geoapify 矢量数据。在约经度 100.574–100.589、纬度 13.912–13.922 范围内，按几何顶点落入范围统计，数据约含 7 处建筑轮廓、24 个地点、33 个有名称的道路片段。该范围用于排查公开地图数据，不是位置回传记录；这是近似计数，跨边界几何可能有遗漏。

因此空白同时来自显示层级及源数据缺失。此次改善已有数据的显示，不生成建筑、店名或门牌，也不承诺与高德 App 的海外数据相同。若需要完整建筑覆盖，必须另外评估数据更完整的服务；单纯更换样式无法补齐。

来源：https://apidocs.geoapify.com/docs/maps/ （Geoapify 底图基于 OpenStreetMap）；现场数据检查使用本站代理返回的原始矢量瓦片。

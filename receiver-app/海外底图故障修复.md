# 海外底图灰屏：2026-09-27

正式站 v12 的地点查询成功，但底图瓦片全部返回 503。服务器记录显示请求仅运行约 3–16 毫秒，没有等待地图服务超时。旧代码将内部异常统一写成“请检查网络”，造成误导。

## 修复

- 移除托管环境禁用的 `caches.default`，改用站点独立的命名缓存。依据：[Cloudflare 官方托管环境缓存限制](https://developers.cloudflare.com/cloudflare-for-platforms/workers-for-platforms/reference/limits/#cache-api)。
- 打开、读取或写入缓存失败时，仍可返回有效地图图片；每次访问上游仍受原有额度限制。
- 区分服务器内部错误和连接地图服务错误。日志只记录固定的失败阶段，不记录密钥、坐标、上游 URL 或原始异常内容。
- 响应头 `X-Map-Cache` 标识 HIT、MISS、BYPASS，方便核对正式服务是否真正使用缓存。
- 不修改原始位置、旧入口权限、发送流程或地图账户配置。

## 必须验证

1. 执行单元测试，覆盖默认缓存禁用、缓存读写失败、缓存命中、预算失败关闭。
2. 正式部署后，直接请求同一张真实底图两次，均应为 PNG；首次为 MISS，随后为 HIT。
3. 运行 `tests/world-production-check.js`：正式首页现有泰国记录、真实底图、地点、刷新、缩放和路线均可显示。截图保留在 `output/playwright/`。
4. 手机宽度浏览器模拟不能声称等同于微信、Safari 或 Android 真机验收。

此文件记录修复及验收方法；本次正式环境的实际执行结果单独保留在交付目录。
